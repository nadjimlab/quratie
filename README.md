# قِرايتي | Qiraati

**قِرايتي** تطبيق Android مجاني يساعد الولي والتلميذ على تنظيم المسار الدراسي وفق المصطلحات والاحتياجات الجزائرية، من خلال جدول الحصص، الواجبات، الفروض، تجهيز المحفظة، التذكيرات اليومية، والمراجعة الذكية.

## المزايا الحالية

يحتوي التطبيق على ملف تلميذ قابل للتخصيص، جدول أسبوعي يمكن إدخاله يدويًا أو عبر تصويره، مركز متابعة يومية، رزنامة العطل، إشعارات محلية، ومساعد دراسي. كما يتضمن شاشة ترحيبية وهوية بصرية مخصصة لتطبيق قِرايتي.

## البنية التقنية

المشروع تطبيق Android أصلي مبني بـ Kotlin وJetpack Compose. تُخزّن بيانات التطبيق محليًا عبر Room، ويُستخدم GitHub Actions لتشغيل الاختبارات وبناء APK تجريبي. تعمل الإشعارات اليومية محليًا ولا تحتاج إلى خادم دائم.

## البناء محليًا

يتطلب البناء Java 17 وAndroid SDK Platform 36. بعد تجهيز البيئة، نفّذ:

```bash
chmod +x ./gradlew
./gradlew testDebugUnitTest
./gradlew assembleDebug
```

ينتج APK التجربة في `app/build/outputs/apk/debug/`.

## الأسرار والخصوصية

لا تضع مفاتيح Gemini أو Firebase أو أي رموز وصول في المستودع. استخدم ملف `.env` محليًا أو GitHub Secrets. ملف `.env.example` لا يحتوي على قيم سرية. لا تُرسل بيانات التلاميذ أو صور الجداول إلى Issues العامة.

بيانات التطبيق المحلية غير مفعّلة للنسخ الاحتياطي التلقائي حفاظًا على خصوصية الولي والتلميذ. قبل إصدار نسخة Production موقّعة، يجب إنشاء مفتاح Release خارج المستودع وربطه بأسرار GitHub Actions.

راجع [سياسة الأمان](SECURITY.md) قبل المساهمة أو الإبلاغ عن ثغرة.

## المصدر التعليمي

Qiraati تطبيق مساعد للتنظيم والمتابعة، ولا يحل محل البلاغات والوثائق الرسمية لوزارة التربية الوطنية الجزائرية. يجب مراجعة أي منهج أو تدرج سنوي مقابل المصدر الرسمي قبل نشره داخل التطبيق.

## إصدار Google Play

لإنشاء ملف Release AAB موقّع، راجع [دليل الإصدار](RELEASE.md) وشغّل Workflow **Android Release Bundle**. لا ترفع ملفات JKS أو كلمات المرور إلى المستودع.
